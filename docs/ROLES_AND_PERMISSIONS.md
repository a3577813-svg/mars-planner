# Роли и права доступа

## Роли

### Ученик 5–7

- видит свою версию планёрки;
- заполняет только свои развороты;
- загружает собственные материалы;
- читает адресованные ему комментарии;
- отмечает свои договорённости.

### Ученик 8–11

Имеет те же базовые права, но работает с версией планёрки 8–11 и её отдельными разворотами.

### Тьютор

- видит только закреплённых учеников;
- просматривает их развороты;
- оставляет комментарии и договорённости;
- меняет статус сопровождения;
- не редактирует ответы ученика и тексты шаблонов.

### Методист

- получает разрешённый обзор по группам и версиям планёрки;
- анализирует прохождение, содержание и сопровождение;
- может участвовать в методической редактуре при отдельном разрешении;
- не изменяет ответы учеников;
- не управляет аккаунтами и системными правами.

### Администратор

- управляет пользователями и ролями;
- закрепляет тьюторов;
- настраивает календарь и учебный год;
- назначает развороты по неделям;
- управляет видимостью;
- редактирует содержание разворотов;
- не должен автоматически получать неограниченный доступ к чувствительным ответам без утверждённого основания.

### Редактор маршрута — планируемая роль

- редактирует тексты, инструкции и шаблоны;
- создаёт версии содержания;
- не управляет пользователями;
- не просматривает ученические ответы без отдельного права.

## Принцип реализации

Матрица должна проверяться на сервере для каждого действия. Клиентский интерфейс может скрывать недоступные элементы, но не является источником истины для безопасности.
