# История версий

## MVP 0.9 — функциональный прототип

### Реализовано

- версии планёрки 5–7 и 8–11;
- 45 разворотов в старшей версии;
- независимое заполнение двух версий;
- адаптация под телефон, планшет и компьютер;
- кабинеты ученика, тьютора, методиста и администратора;
- календарь учебного года;
- маршрут и первая страница ученика;
- комментарии тьютора;
- назначение разворотов по неделям;
- управление видимостью разворотов;
- переход к редактированию содержания;
- редактирование названий, инструкций, вопросов и подписей;
- базовая система ролей и маршрутов;
- единый модуль назначений;
- единый сервис локального хранения;
- синхронизация изменений между вкладками.

### Известные ограничения

- данные хранятся только в браузере;
- нет общей базы между устройствами;
- нет полноценной серверной авторизации;
- права пока не защищены сервером;
- фотографии и реальные данные учащихся нельзя использовать в рабочем режиме;
- интерфейс постепенно переводится с enhancer-компонентов на устойчивую компонентную архитектуру.

## Планируемая версия 0.10 — живой маршрут

- единая дизайн-система;
- новый главный экран ученика;
- карточка текущей недели;
- актуальный этап года;
- ближайшие события;
- компактная навигация по разворотам;
- более заметное сообщение тьютора;
- договорённости;
- проверка адаптивности на трёх типах устройств.
