# Цифровая планёрка МАРС

Цифровая планёрка МАРС — модуль сопровождения образовательного маршрута ученика.

Она не заменяет электронный журнал и не является системой тотального контроля. Планёрка помогает ученику видеть свой путь, понимать следующий шаг, фиксировать опыт и получать поддержку тьютора.

## Текущий статус

- Версия: MVP 0.9
- Состояние: функциональный прототип
- Использование реальных данных учащихся: запрещено до завершения этапа защищённого хранения и авторизации

## Основные принципы

1. Планёрка — личный живой маршрут, а не электронный дневник.
2. Тьютор сопровождает, а не контролирует.
3. Администратор управляет содержанием через интерфейс, а не через код.
4. Любой экран должен помогать понять следующий осознанный шаг.
5. Безопасность является обязательным условием реального запуска.
6. До подключения защищённой инфраструктуры используются только демонстрационные данные.
